# 更新记录

## 1.0.2 — 2026-10-01

- 新增纯白阅读主题（#ffffff），保留原有纸白、暖纸、青瓷、月白和夜间。
- 正文划线去掉聚焦围框与阴影；跨行保持柔和荧光底色，夜间文字继承正文色。
- 书库升级为 C「清晰书目」：分类导航、小封面、格式筛选、对齐进度与更多菜单。
- 阅读工具栏闲置自动隐藏，目录移到底部；修复分页残字与分割缝隙。
- AI 伴读支持拖动分割、紧凑标题、选文上下文与快捷提示词管理。
- 修复书库菜单 Esc 关闭整个阅读器，以及笔记入口打开划线列表的问题。
