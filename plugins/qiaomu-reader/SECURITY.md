# 安全问题 / Security

请不要在公开 Issue 中粘贴令牌、私人会话、工作区内容或可复现的敏感数据。发现安全问题时，请使用 GitHub 仓库的 **Report a vulnerability** 私密入口；若该入口不可用，请先联系维护者 [@joeseesun](https://github.com/joeseesun)，协商私密报告方式。

Do not post credentials, private conversations, or workspace content in public issues. Use GitHub's private vulnerability reporting when available, or contact [@joeseesun](https://github.com/joeseesun) to arrange a private report.
